# Paystub Analysis Tool

A Python-based paystub analysis tool that extracts payroll data from PDF paystubs, stores the information in a structured database, and generates insights into earnings, deductions, taxes, and income trends over time.

## Install

1. Install the required dependency:

```bash
pip install pdfplumber
```

2. Clone the repository:

```bash
git clone https://github.com/cisco95/PaystubAnalysis.git
cd PaystubAnalysis
```

### Features

- Extract payroll information from PDF paystubs
- Store paystub data in a local database
- Track income history across employers and pay periods
- Analyze gross pay, net pay, taxes, and deductions
- Generate income and payroll summaries
- Build a historical dataset for financial analysis
